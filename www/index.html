SUDOKU SLEUTH

A hidden grid where every row and column holds unique digits from a wider pool. Click a row to select it, guess a full row at a time, and read the feedback — green means right digit, right spot; yellow means it's in the row, wrong spot; gray means it's not in that row at all. Use column overlaps across rows to deduce faster. You share one guess budget for the whole grid.
How to play Each puzzle hides an N×N grid filled with digits drawn from a pool larger than N, arranged so no row or column repeats a digit — like a Sudoku region with room to spare. You don't see the grid. Tap a row number to select it, then tap out that full row's digits on the keypad below the grid (e.g. "3164" for a 4-wide row) to get per-digit feedback: green if that digit is in that exact spot, yellow if it's somewhere else in that row, and gray if it doesn't appear in that row at all. The main grid always shows each row's latest guess feedback at a glance. All your guesses across every row draw from one shared budget, so once you know a digit's column position from one row, you can rule it out of that column in every other row. Solve every row before the budget runs out to win.
